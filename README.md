# K. Patel Chemopharma

Official corporate website for **K. Patel Chemopharma Private Limited**, established in 1974. Manufactures and exporters of Dyes, Pigments, and specialty colorants.

## Features
- Fully responsive modern design (Desktop, Tablet, Mobile)
- Clean URL architecture configured via `vercel.json`
- Dedicated product catalog and industries breakdown
- Integrated B2B Bulk Sales quotation forms

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Vercel (for production hosting)

## Deployment
This project is Vercel-ready. To deploy:
1. Push this repository to GitHub.
2. Import the project in Vercel.
3. Vercel will automatically detect `vercel.json` and deploy the static assets with clean URLs and security headers.
